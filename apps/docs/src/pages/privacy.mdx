## Server log files

When you use this website, technically necessary data is automatically transmitted to
our server and recorded in log files: IP address, date and time of the request, name
and URL of the retrieved file, the website from which the request came (referrer URL),
access status/HTTP status code, browser type, language and version of the browser
software, and operating system.

This processing is technically necessary to display the website to you and to ensure
its security and stability.

## Analytics

We use **Matomo** to understand which documentation pages are read and how they are
found, so that we can improve them. Matomo is a web analytics service. The information
collected is stored exclusively on servers in Germany.

**This site does not use tracking cookies.** Matomo is configured to run without
cookies, and nothing is stored on or read from your device for analytics purposes. For
that reason no cookie banner is shown.

We use Matomo with IP masking: your IP address is shortened before it is stored, and
the shortened address is also what is used to derive your approximate location.

The following is recorded for each page you view:

- the page address and page title
- the page you navigated from, including navigation within this site
- an approximate location derived from the shortened IP address
- browser, operating system, device type, screen size and language
- how long you spend on a page
- links and file downloads you click

The legal basis for processing data with Matomo is Art. 6(1)(f) GDPR (legitimate
interests). Further privacy information about Matomo is available at
[matomo.org/privacy-policy](https://matomo.org/privacy-policy/).

## Your right to object — opt out of analytics

You can object to this analytics processing at any time, with effect for the future.
Use the checkbox below. Your choice applies to this documentation site.

<MatomoOptOut />

Opting out stores a small cookie on your device so that we can remember your decision.
This is the only cookie this site sets, and it is set only if you opt out.
